Entry for the [Texts From Your Future Self](https://make.fun/c/u-motasimfuad-texts-from-your-future-self-dd44595e) competition on [make.fun](https://make.fun).

`main.py` (pure Python stdlib, no dependencies) writes one funny text message
from the writer's future self to `/output/entry.txt` — under 200 characters,
funny on its own, no setup, no explanation.

Run it:

```sh
python3 main.py
```
